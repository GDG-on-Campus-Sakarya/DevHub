# DevHub Flutter Starter

## Başlangıç
- Flutter SDK kurulu olmalı.
- Terminalde `flutter pub get` çalıştırın.
- Web için `flutter run -d chrome` çalıştırın.

Firebase paketleri pubspec.yaml içinde bulunur; bağlantı henüz yapılmadı. Firebase sorumlusu FlutterFire CLI ile `firebase_options.dart` üretip `main.dart` dosyasını güncellemelidir.

## Görev alanları
- Auth ve profil: `lib/screens/auth/`, `lib/screens/profile/`
- Projeler: `lib/screens/projects/`
- Başvurular: `lib/screens/applications/`
- Modeller: `lib/models/`
- Servisler: `lib/services/`
- Ortak bileşenler: `lib/widgets/`
